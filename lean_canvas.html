Lean Canvas — Sentry Push

Перехватчик чувствительных данных для git push и запросов к AI-агентам.

2

Проблема

  • AI-агенты и разработчики случайно передают во внешние системы секреты (ключи, пароли, PII) при push и в запросах к агентам
  • 81% security-команд не видят, как AI-агенты используют данные компании
  • AI-ассистированные коммиты содержат утечки секретов в 2 раза чаще обычных
Существующие альтернативы
  • GitGuardian, TruffleHog, Gitleaks — только git push, не видят агентские запросы
  • Встроенные secret scanners AWS/GCP
  • Ручной код-ревью, корпоративные DLP
4

Решение

  • Pre-push hook + детекция секретов (regex + entropy)
  • MCP-прокси для перехвата запросов к AI-агенту (v2.0)
  • Approve / hold / reject с уведомлением в CLI и Slack
8

Ключевые метрики

  • Точность детекции (≥90%) и доля ложных срабатываний
  • Установки / ★ на GitHub, число команд-пилотов
  • Retention через 3 месяца; MRR от платных тарифов
3

Уникальная ценность

«Единственный инструмент, который проверяет не только git push, но и сами запросы к AI-агентам — закрывая слепую зону, о которой не знают 81% security-команд.»

Конкуренты
  • GitGuardian, TruffleHog, Gitleaks, Snyk
  • Встроенные scanners облачных провайдеров
  • JTBD-альтернатива: ручная бдительность разработчика и код-ревью
9

Скрытое преимущество

  • Проприетарный датасет паттернов секретов и ложных срабатываний из реального использования
  • Первыми закрепились в нише перехвата AI-агентов (MCP)
  • Доверие open-source community — не покупается бюджетом конкурентов
